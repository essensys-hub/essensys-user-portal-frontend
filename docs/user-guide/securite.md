# Sécurité

> Cet écran évolue : son apparence peut changer légèrement d'une version à l'autre.

## À quoi sert cet écran

Activer et désactiver l'alarme de la maison à distance, avec votre code, et couper ou rétablir les prises de sécurité.

![L'écran Sécurité](images/securite-desktop.png)

## Y accéder

Menu **Sécurité** (ordinateur), **Sécurité** en bas de l'écran (téléphone), ou la carte **Sécurité** du tableau de bord.

## L'écran en détail

1. **Code alarme** : saisissez votre code à **4 chiffres**, le même que sur le clavier de l'alarme.
2. **Activer l'alarme** : met l'alarme en service.
3. **Désactiver l'alarme** : coupe l'alarme.
4. **État des prises de sécurité** : **Prises pilotées** (alimentées normalement), **Prises coupées**, ou **État inconnu** quand l'armoire n'a pas encore transmis l'information. Après une commande, le portail affiche **En attente de l'armoire** le temps de relire l'état.
5. **Couper** : coupe les prises de sécurité (fer à repasser, plaques de cuisson…). Le portail demande une **confirmation** avant d'envoyer la commande ; **Annuler** n'envoie rien.
6. **Rétablir** : remet le courant sur les prises de sécurité.
7. **Information** : le système fonctionne en **boucle ouverte**. La commande d'alarme est envoyée, mais le portail ne reçoit pas de confirmation de l'état de l'alarme.

Les boutons **Couper** et **Rétablir** sont grisés quand l'armoire est hors ligne. Un scénario (par exemple « Je sors ») peut aussi couper ou rétablir les prises : voir **[Scénarios](scenarios.md)**.

> **Important** : après une commande d'alarme envoyée à distance, assurez-vous par un autre moyen (voisin, caméra, retour sur place) que l'alarme a bien changé d'état. Ne communiquez jamais votre code, y compris dans un signalement.

![L'écran Sécurité sur téléphone](images/securite-mobile.png)

## Messages courants

| Message | Que faire |
|---|---|
| Code invalide | Le code doit comporter exactement 4 chiffres. |
| Commande envoyée | La commande est partie ; vérifiez l'état réel de l'alarme. |
| Coupure des prises de sécurité : commande envoyée | L'armoire coupe les prises sous quelques secondes ; l'état se met à jour. |
| Commande validée (test, non exécutée) | Le mode test est actif : rien n'a été envoyé à l'armoire. |
| Armoire hors ligne | Les commandes des prises reviennent dès que l'armoire est de nouveau joignable. |

Utilisez **[Signaler un problème](https://www.essensys.fr/signaler)**, sans jamais indiquer votre code.
